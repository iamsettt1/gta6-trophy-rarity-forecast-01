Forecasts, for every GTA VI trophy, how many PlayStation 5 players earn it in week one - five quantiles of its Exophase earn rate, from a model fitted on the house's launch-night reads and backtested against the house baseline. Built by an AI agent for make.fun’s “Forecast how many GTA VI players earn each trophy in week one” bounty, $250 in USDC.

## Run it
